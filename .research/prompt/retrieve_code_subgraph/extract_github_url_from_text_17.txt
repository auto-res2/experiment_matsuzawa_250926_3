DPL models learning curves (validation loss vs. optimization epochs) as power law functions: ˆf(λ, b) := αλ + βλ b−γλ. Instead of fitting individual power laws, a single neural network g: Λ → R3 maps hyperparameter configurations λ to the power law coefficients (α, β, γ). The posterior mean and variance from the ensemble are used with the Expected Improvement (EI) acquisition function to recommend the next hyperparameter configuration. A multi-fidelity strategy is employed where selected configurations are advanced by a small budget step (e.g., one epoch) rather than run to full convergence, allowing for dynamic pausing and incremental training.
