The methodology casts hyperparameter optimization as a bi-level optimization problem that can be solved by gradient descent in the hyperparameter space. The algorithm operates in two decoupled steps: first solving the inner Lasso problem to identify the support of the regression coefficients, then iteratively computing the Jacobian by restricting updates to this identified support.
