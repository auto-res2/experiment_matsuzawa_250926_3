The conditional entropy term of the acquisition function is computed using a Monte-Carlo approximation for function maximums 'f*', further employing sequential Gauss-Hermite quadrature and moment matching to approximate conditional posteriors. The acquisition function is optimized using L-BFGS with random initialization.
