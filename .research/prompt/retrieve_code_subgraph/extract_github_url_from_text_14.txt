# Paper Outline
DyHPO is a Bayesian Optimization approach built upon Gaussian Processes (GP). It employs a novel deep kernel for GPs, which inputs the hyperparameter configuration, the budget (normalized), and the past learning curve into a neural network (composed of linear and convolutional layers) before feeding into a squared exponential kernel. This deep kernel captures the learning curve dynamics to model the similarity of configurations across different budgets. For configuration selection, DyHPO utilizes a multi-fidelity version of Expected Improvement (EIMF), which dynamically adapts the budget allocation by choosing the most promising candidate to train for a small additional budget at each step, ensuring exploration by slowly increasing fidelity.
