FLoRA operates by leveraging meta-learning techniques and local, asynchronous HPO at each party. Each participating party independently runs an adaptive HPO scheme (e.g., Bayesian Optimization) to generate a set of (hyper-parameter, loss) pairs. These per-party sets are then collected by a central aggregator. The aggregator constructs a unified loss surface (a function mapping hyper-parameters to estimated loss) using one of four proposed aggregation methods: Single Global Model (SGM), SGM with Uncertainty (SGM+U), Maximum of Per-party Local Models (MPLM), or Average of Per-party Local Models (APLM). The optimal hyper-parameter configuration is then selected from this aggregated loss surface, and a single federated training round is performed using these recommended hyper-parameters to produce the final global model.
