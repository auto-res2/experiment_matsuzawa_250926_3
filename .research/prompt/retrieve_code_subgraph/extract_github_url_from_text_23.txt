# Paper Outline
FLoRA leverages meta-learning techniques by utilizing local and asynchronous HPO at each party. Each party independently performs HPO (e.g., Bayesian Optimization) to generate a set of (hyper-parameter, local loss) pairs. These pairs are then collected by a central aggregator, which constructs a unified loss surface across the entire hyper-parameter space. Four distinct methods are proposed for constructing this unified loss surface: Single Global Model (SGM), SGM with Uncertainty (SGM+U), Maximum of Per-Party Local Models (MPLM), and Average of Per-Party Local Models (APLM). The aggregator then selects the optimal hyper-parameter configuration from this surface, which is subsequently used for a single round of federated training.
