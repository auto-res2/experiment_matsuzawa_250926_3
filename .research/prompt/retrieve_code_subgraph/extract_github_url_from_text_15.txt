BOIL models the cost-sensitive black-box function as a Gaussian Process (GP) over the joint space of input hyperparameters (x) and number of training iterations (t), using a product kernel. The parameters of this Sigmoid function are learned directly from the data by maximizing the GP's log marginal likelihood.
